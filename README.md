# パチモン — PACHIMON

ポケモンの パクリゲー「パチモン」。ビルド不要の **静的 Web サイト** として動く、
ミニ モンスター収集 RPG です。スプライトは 画像ファイル なし — **すべて コードで Canvas 描画** しています。
ひとり用は 外部ライブラリ なしで 動きます。**ネットたいせん** だけは、同梱の PeerJS と
公開シグナリング サーバーを つかいます（ビルドは 不要）。

> ※ 本家とは いっさい カンケイ ありません（カンケい あるかもしれません）

---

## 遊び方

`index.html` を ダブルクリック するだけ で 遊べます（`file://` でも 動作）。

お好みで ローカル サーバーを 立てる 場合:

```bash
python -m http.server 8321
# http://127.0.0.1:8321/ を ブラウザで 開く
```

## 操作

| 操作 | キーボード | タッチ |
|------|-----------|--------|
| いどう | WASD / ↑↓←→ | 画面下の 十字パッド |
| はなす・しらべる・すすめる | E / Enter / Space | A ボタン |
| メニュー | M | 画面右上「メニュー」 |
| 全体マップ | N | 画面右上「マップ」 |
| メニューを とじる | Esc / M | ✕ / B ボタン |
| 全体マップを とじる | N / Esc | ✕ / B ボタン |
| メニュー内の えらぶ | ↑↓←→ で フォーカス移動 → Enter | タップ |

キーを ながおし しても、Enter や 移動キーが れんぞくで はつどう しない ように してあります（キーリピート むこう）。

**キーボード だけ で ぜんぶ あそべます。** タイトル・御三家えらび・メニュー・バトル・はなし ボックス は
すべて ↑↓←→ で フォーカスを うごかし、Enter（または Space）で けってい できます。
フォーカス中の 要素は 黄色い わくで 表示されます。メニュー内は Tab / Shift+Tab でも 移動できます。

- 草むら（くらい 緑の 高い草）を 歩くと パチモンが とびだして きます
- 建物の ドアのまえに 立って **上向きで 話す** と 入れます（パチモンセンター / パチマート）
- NPCに 話しかけると クエストや ヒントが もらえます

## ネットたいせん

メニュー → **たいせん** タブ から、ほかの パチモン トレーナーと たいせん できます。
ルームを つくる ひとが **シングル / ダブル** を えらび、あいては その けいしきで たいせんします。

1. ルームを つくる ひと が けいしき（シングル / ダブル）を えらんで「ルームを つくる」を おす
2. 画面に 出た **6もじの ルームコード** を あいてに おしえる
3. あいては「ルームにはいる」で コードを 入力
4. マッチング できたら、おたがいの パチモンが Lv50 になって たいせん かいし

ルール:

- おたがいの パチモンは **Lv50 の コピー** で たたかう（HP・PP まんたん、状態異常なし）
- けいけんち・おかね・バッジ・ストーリー フラグは **もらえない**
- わざ・こうかん・バッグ・こうさん は ふつうどおり つかえる
- **ダブルバトル** では おたがい **2たいずつ** 場に でる。わざ・こうかん・どうぐは
  それぞれの スロットごとに 1つずつ えらぶ
- ダブルで ひんしに なった スロットは、ひかえの 先頭が **じどうで とうじょう** する
  （おたがいの ゲームで 同じ 順番に なるよう、えらぶ 画面は でません）
- **範囲わざ** は ダブルで あいて ぜんいん、または となり ぜんいん（みかた ふくむ）に
  あたり、ダメージは **0.75ばい**
- ボールは つかえない（あいての パチモンは つかまえられない）
- たいせん中に つかった どうぐは **ほんものの バッグから は へらない**。
  たいせん中だけ の 使用数で かぎりが ある（キズぐすり 3こ なら 3かい まで）
- たいせんが おわると、パーティは **たいせん前の レベル・HP・PP・もちもの の まま** にもどる
- たいせん中に つながりが きれると その たいせんは ちゅうだん され、パーティは もとどおり

つうしん:

- ブラウザの **WebRTC（PeerJS）** で P2P 接続します。`peerjs.min.js` を 同梱
- ルームコードの マッチングだけ、公開の **PeerJS クラウド サーバー** を つかいます。
  たいせんには **インターネット接続** が ひつよう です
- たいせんの 計算は おたがいの ブラウザで **同じ 乱数シード** から 同じ 順番に すすみ、
  毎ターン **チェックサム** を くらべて ずれを なおします

## 目標

パチもん島で 御三家（フシギダメ / ヒトカゲン / ゼニガメラ）を 選び、草むらで パチモンを 捕まえて
育てながら、島を ぐるっと めぐって **6つの ジムバッジ** を 集めます。

1. **いわの ジム**（北西 ガレキ山脈 / リーダー ガンゴロウ）— 最初の 目標（Lv27〜31）
2. **しずくの ジム**（南東 みなと町 / リーダー ウズミ）— いわの バッジ 後（Lv36〜40）
3. **しんりょくの ジム**（中央西 こだまの深森 / リーダー モリーヌ）— バッジ 2こ から（Lv45〜49）
4. **ほのおの ジム**（東 かざんの いただき / リーダー カエンジ）— バッジ 3こ から（Lv53〜58）
5. **いなずまの ジム**（北 かみなり台地 / リーダー ライデン）— バッジ 4こ から（Lv62〜66）
6. **こおりの ジム**（北東 こおりの さかみち / リーダー ヒョウガ）— バッジ 5こ から（Lv68〜72）

6つの バッジを そろえると チャンピオンゲートが 開き、**チャンピオンロード** で ライバル
**パチロー**（Lv76〜82 の 6たい）と 最終決戦。勝てば エンディングです。
**クリア 目安は レベル85 前後**。ワールド エンカウントは チャンピオンロードで Lv74〜85、
しろい 原野で Lv70〜78 まで 育つので、寄り道して 育てるほど 楽に なります。

バッジが たりない あいだは **バッジゲート** が ゾーンの さかいを ふさぎます。ゲートは
道の さかい目に 設置され、道の ない さかいは 木や いわで ふさがれるので、飛び越えたり
横から 回りこんだりは できません。ゲートは マップ さくせいじに ゾーンの さかいから
じどうで つくられる ため、どの 入口からでも ひつよう バッジ数が たりないと とおれません。

| バッジ | ひらく ゾーン |
|--------|----------------|
| 0こ | わかば草原・ざわめきの森・かわべの こみち・ガレキ山脈 |
| 1こ | なぎさ街道・みなと町・すなの おか・あなぐらの 鉱山 |
| 2こ | こだまの深森・いずみの 湿地 |
| 3こ | かざんの いただき・ささやぶの 小径 |
| 4こ | かみなり台地・たきつぼの 滝・わななきの 渓谷・こだいの 遺跡 |
| 5こ | こおりの さかみち・しろい 原野 |
| 6こ | チャンピオンロード |

一方通行の **段差（LEDGE）** は 南にだけ おりられ、来た道を そのまま 引き返す ことは できません。

### ストーリー ガイド

- 画面 左上の **「もくてき」ピル** に、いま やるべき ことが 常に 表示されます
- メニュー → **ガイド** タブ で、**クリア条件** と 7つの 目標（6バッジ + ライバル）の 進み具合を チェック
- **N キー**（または「マップ」ボタン）で **全体マップ** を 開くと、いまの 場所・目標地点・
  バッジゲートの 必要数が わかります
- 道の 要所に いる **みちあんない** NPC と かんばん が、次の 行き先を 教えてくれます

## システム

- **パチモン 210種**（御三家 + 進化系 + ずかん No.85〜134 の 新種50体 + 新しく 追加した 76の 進化先。名前は すべて 本家から ほんの少し だけ 変えてある）／ **わざ 141種**
- **新しく 追加した 進化** — もともと 進化しなかった 64種に 1回目の 進化先、
  一部の 2しんかめ 12種に 2回目の 進化先を 追加。進化レベルは、進化前の パチモンが
  やせいで 手に はいる レベルと、進化後の 種族値の 強さに あわせて 個体ごとに 設定
  （Lv22〜80）。進化先は もとの かたち・いろを いかした 専用スプライトで、
  こうたい・もよう・アクセサリーで 見わけられます
- **18タイプ** の 完全な 相性表（ばつぐん / いまひとつ / こうかなし）。物理・特殊・変化の 3分類
- **6能力**（HP / こうげき / ぼうぎょ / とくこう / とくぼう / すばやさ）＋ **めいちゅう / かいひ**
  - **25種類の せいかく**（上がる能力と 下がる能力の 組み合わせ）
  - **26種類の とくせい**（しんりょく / もうか / げきりゅう / せいでんき / ふゆう / マルチスケイル /
    あついしぼう / こんじょう / テクニシャン / がんじょう / スナイパー / すながくれ / マジックガード /
    だっぴ / かそく / アイスボディ / うるおいボディ / いかく / じしんかじょう など）
  - とくせいの 配分は 種類ごとに ほぼ 同じ（7〜9種）に なるよう 調整
  - パチモンは それぞれ **11〜14個の わざ** を おぼえ、**141種の わざ すべて**を だれかが おぼえます
  - **個体値（IV 0〜31）・努力値（EV 0〜1000、合計 6000まで）**、レベルアップで EV を 獲得
  - 努力値の 能力への 反映は **ev/8**。努力値を ふりきっても 能力差が つきすぎない ように 調整
  - **もちもの**（たべのこし / オレンのみ / いのちのたま / こだわり系 / きあいのハチマキ など）
- **能力ランク**（−6〜+6）・**急所**・**命中/回避**・**天候**（にほんばれ / あまごい / すなあらし / あられ）
- **設置技**（リフレクター / ひかりのかべ / やどりぎのタネ / みがわり / まもる）
  - **まもる** は 1回目 100%、れんぞくで つかうたび せいこうりつが **1/3** に さがる（33% → 11% → …）。
    あいてを ねらう へんかわざも ふせぐ。わざ・どうぐ・こうかん・にげる など、まもる いがいの こうどうで カウントは リセット。
    **ネットたいせんでも 同じ カウント**を つかい、ターンの 状態 スナップショットで おたがいに 同期します
    （ダブルバトルでは 場に でている 2たい ぶんを それぞれ 同期）
- **状態異常**（どく / もうどく / まひ / ねむり / やけど / こおり / こんらん）
- わざの 特性: 複数ヒット / 反動 / 吸収 / 溜め / 反動ターン / 優先度 / 追加効果 / 能力変化
  - **ふいうち** は あいてが その ターン ダメージわざを つかわない とき（どうぐ・こうかん・へんかわざ・すでに うごいた あと）は しっぱいする
  - **反動** で こうしゅ が たおれた ばあいも、あいての こうたい・しょうり と 同じ ターンに 正しく ひんし 処理する
  - **範囲わざ** は ダブルバトルで あいて ぜんいん（ふぶき / スピードスター / マジカルシャイン / なきごえ など）、または
    となり ぜんいん（じしん / なみのり / じならし / いわなだれ など、みかた ふくむ）に あたる。ダメージは **0.75ばい**
- **本家準拠の 捕獲率**（ボール補正・HP・状態異常で 変動）と **捕獲アニメーション**
- **経験値曲線**（fast / normal / mediumSlow / slow）・**EV獲得**・レベルアップでの **わざ習得**・**進化**
  - 獲得経験値は **1.2倍** を もとに、ゲーム全体で **これまでの 40%** に 調整（テンポ重視）
  - **その しょうぶで 先頭に 出た 個体** は **100%**
  - 出ていない **ひかえの 生存個体** は **75%**（ひかえでも レベルアップ します）
  - **レベル差ボーナス** — 自分より レベルの たかい あいてを たおすと、1レベルにつき **+15%**（さいだい **4ばい**）の 経験値
  - **がくしゅうそうち** を もっていると、ひかえの 取り分が **100%** に アップ
  - レベルアップで 新しい わざを 覚える とき、**おぼえる / おぼえない** を えらべます。
    すでに 4つ 覚えている ばあいは、**どの わざを わすれるか** も えらべます（わすれずに キャンセルも 可）
  - メニュー → パーティ → パチモンの **そうこう** から **「わざを おもいだす」** で、
    これまでに 覚えた わざを いつでも おもいだせます（4つの ばあいは いれかえ）
- **色違い**（1/512）— 図鑑・パーティ・バトルで きらきら 光ります
- **パーティ 6匹 + ボックス**（あずける / ひきだす、ならびかえ、先頭交代）
- **パチモンセンター**（無料 かいふく）と **パチマート**（パチコインで 買い物）
- **パチずかん**（未捕獲は シルエット表示、色違い・タイプ・6能力・**種族値**を 確認）
- **つりざお** — ウキビトに 話しかけて もらい、水辺で しらべると みずの パチモンが つれます
- **見て わかる 場所だけ エンカウント** — エンカウントは **草むら（TALL）** の うえだけ。
  はなばたけ・すな・いわ・ゆき・かざん の タイルは 景色として 楽しめますが、パチモンは でません。
  草むらは マップの かくだいに あわせて 少し 増やして あります。
  **進化後の パチモン** が やせいで でるのは、**チャンピオンロード** と **チャンピオンロードの 泉** だけです
- **かくしアイテム** — マップの きらめきを しらべると どうぐが 手に入ります（全16か所）
- **ジム & バッジ** — 6つの ジムの リーダーを 倒すと バッジが 手に入り、HUD に 並びます。
  バッジ数で **ゾーンゲート** が 開き、レベルの ひくい ゾーンから 順番に すすめる ように なります
- **ゾーンゲート** — ゾーンの さかいを 自動で ふさぐ ゲート。道の さかいは ゲート、道の ない
  さかいは 木・いわで ふさがれます。全体マップには ゾーンごとの 必要バッジ数が 表示されます
- **ストーリー ガイド** — 目標ピル / ガイドタブ / 全体マップ / 道案内NPC / かんばんで 迷わず 進行
- 全滅すると **さいごに つかった パチモンセンター** の まえへ ひなん（自動で 全回復）。
  所持金は **20%** だけ 失います（パクリ なので 優しい）
- **ネットたいせん** — 6もじの ルームコードで つながって **シングル / ダブル**。おたがいの パチモンは **Lv50 の コピー**、
  けいけんち・おかね なし、たいせん後の パーティは そのまま。わざ / こうかん / どうぐ / こうさん / 範囲わざ 対応
- **BGM 内蔵** — タイトル / ワールド / バトル / しょうりジングル / エンディング の チップチューン5曲（WebAudio で 生成、画像・音声ファイル なし）
- バトルの **ダメージポップ・ばつぐん/きゅうしょフラッシュ・ログアニメ**、**鳴き声**、**HP が 少ないと 警告音**
- **わざ 141種 すべてに 専用エフェクト** — はなび / みずしぶき / かみなり / はっぱ / こおり /
  パンチ / いわ / シャドー / ビーム / 突進 / オーラ / 天候 などを、わざ ID・タイプ・分類から
  描き分けます。ビームは 発射元から 相手へ のび、弾は 飛び、打撃は ヒット時に はじけ、
  変化わざは 自分や 相手を オーラで つつみます。地震系は 画面ゆれ、全天候は 専用の 粒子つき
- **シルエットで 見わける 210種** — 種族 ID から 決定論的に ツノ・翼・マント・しっぽ・ヒレ・
  トゲ・かんむり・触角・肩アーマー・浮遊オーブ・リボン・胸の エンブレム・植物・オーラ・触手
  などを 組み合わせ、色や 模様だけに たよらず かたちで 種族差が 出るように しています
- **セーブスロット 3個** — タイトルの「はじめから / つづきから」で スロットを えらべます
  - 各スロットに 先頭パチモン・レベル・ずかん数・プレイ時間・場所・保存日時 を 表示
  - スロットごとに **オートセーブ**（localStorage キー `pachimon_save_v1_slot1` 〜 `slot3`、セーブさきは `pachimon_active_slot`）
  - 旧バージョンの 1スロット セーブ（`pachimon_save_v1`）は 起動時に スロット1へ 自動で ひっこし（この バージョンの 初回起動時は、下記の リセットが さきに はたらきます）
  - 努力値バランスの 変更に あわせ、**この バージョンを はじめて ひらいた ときだけ**、旧セーブ（3スロット + 旧1スロット）を 自動で 削除します。フラグ `pachimon_save_wipe_v2_ev_rebalance` を 保存するので、2回目 いこうは 消えません
  - メニュー → レポート で **セーブさきの 切替**（いまの レポートを 別スロットへ 保存）と **スロットの 削除** が できます
  - タイトルの スロット えらびで「けす」を 押すと、その スロットだけ 消せます
- 効果音・BGMとも メニュー → レポート →「サウンド」で ON/OFF

## 技術メモ

- ビルド ツール 不要。HTML + CSS + classic JS のみ（module も bundler も 不使用）
- ワールド は **252×216 タイル**（1タイル 36px、約54,000マス）。もとの 168×144 から
  **1.5倍** に ひろげ、**23この だえんローブ**（うち 4つは けしき用の 半岛・いわば）を みずで わけ、ほそい **陸橋** で つないだ
  **非矩形の 島** に、**20ゾーン**（はじまりの町 / わかば草原 / ざわめきの森 / ガレキ山脈 /
  なぎさ街道 / みなと町 / こだまの深森 / かざんの いただき / かみなり台地 / こおりの さかみち /
  チャンピオンロード + かわべの こみち / すなの おか / あなぐらの 鉱山 / いずみの 湿地 /
  ささやぶの 小径 / たきつぼの 滝 / わななきの 渓谷 / しろい 原野 / こだいの 遺跡）を 配置。
  2マス幅の 道で 各ジムへ つながり、ゾーンの さかいには バッジゲートと 木・いわの 障害物を
  自動配置して、レベルの たかい ゾーンへ いきなり 入れないように しています。
  一方通行の 段差（LEDGE）も 進行の ショートカットに なります
- **20ゾーン それぞれの 景観** — `game.js` の `ZONE_THEMES` に ゾーン別の 配色・地面モチーフ・
  道・草むら・木・岩・花・水・段差・ゲート・環境パーティクル（花びら / ほたる / 胞子 / 砂 /
  波しぶき / 火の粉 / 雪 / 金の ちり / 落ち葉 / 水しぶき / トンボ など）を 定義。
  タイルごとに 所属ゾーンの テーマで 描くので、境界の 道や 草むらも 自然に つながります
- 地形は **24×24タイルの チャンク** ごとに Canvas へ 事前描画し、画面に 見える チャンクだけを
  描画します。大きな マップでも メモリと 描画負荷を おさえています
- スプライトは `drawPachimon(ctx, id, x, y, scale, time, opts)` で 毎フレーム 描く 方式 の ため、
  拡大 しても ボケず、絵 の 追加 は `sprites.js` の `ART` 表に 1行 足す だけ。色違いは 色相シフトで 表現
- BGMは `game.js` の `Music` オブジェクト（音符テーブル + 先読みスケジューラ）。曲 の 追加 は `Music.themes` に 1曲 分の データ を 足す だけ
- データ（種族値・わざ・エンカウント・トレーナー・アイテム）は `data.js` に 集中。バランス調整 は そこ で
- 能力値は 本家準拠の `statAt(base, level, isHp, iv, ev, nature, key)` で 計算。
  IV / EV / 性格 / 持ち物 / 色違い は モンスター オブジェクトに 保存され、旧セーブでは デフォルト値で 補完
- ダメージは `calcDamage(atk, def, move)` に 集約（物理/特殊・タイプ一致・相性・急所・天候・壁・特性・持ち物）
- ネットたいせんは **決定論的 ロックステップ**。ホストが 乱数シードを くばり、シミュレーション用の
  乱数は `battle.js` の `brng()` に 集約。おたがいの ゲームが 同じ 順番で 同じ 計算を して、
  毎ターン 状態の チェックサムを 交換。ずれた ときは ホストが スナップショットを 送って なおします。
  こうたい・どうぐ・ターン終了の 順番も ホスト → ゲスト の 固定順に そろえています
- ネットたいせんの 接続だけ **PeerJS**（`peerjs.min.js` を 同梱）と 公開 PeerJS クラウドを 使用。
  ひとり用の ゲーム本体は これまでどおり 外部依存なしで 動きます
- キーボード そうさ は `game.js` の `moveFocus` / `focusables` / `trapFocus` で 実装。
  div 型 の クリック要素 は `tabindex="0" data-kbd` を つけると Enter / Space で はっか される
