# パチモン — PACHIMON

ポケモンの パクリゲー「パチモン」。ビルド不要・依存ゼロの **静的 Web サイト** として動く、
ミニ モンスター収集 RPG です。スプライトは 画像ファイル なし — **すべて コードで Canvas 描画** しています。

> ※ 本家とは いっさい カンケイ ありません（カンケい あるかもしれません）

---

## 遊び方

`index.html` を ダブルクリック するだけ で 遊べます（`file://` でも 動作）。

お好みで ローカル サーバーを 立てる 場合:

```bash
python -m http.server 8321
# http://127.0.0.1:8321/ を ブラウザで 開く
```

## 操作

| 操作 | キーボード | タッチ |
|------|-----------|--------|
| いどう | WASD / ↑↓←→ | 画面下の 十字パッド |
| はしる | Shift を 押しながら | — |
| はなす・しらべる・すすめる | E / Enter / Space | A ボタン |
| メニュー | M | 画面右上「メニュー」 |
| メニューを とじる | Esc / M | ✕ / B ボタン |
| メニュー内の えらぶ | ↑↓←→ で フォーカス移動 → Enter | タップ |

**キーボード だけ で ぜんぶ あそべます。** タイトル・御三家えらび・メニュー・バトル・はなし ボックス は
すべて ↑↓←→ で フォーカスを うごかし、Enter（または Space）で けってい できます。
フォーカス中の 要素は 黄色い わくで 表示されます。メニュー内は Tab / Shift+Tab でも 移動できます。

- 草むら（くらい 緑の 高い草）を 歩くと パチモンが とびだして きます
- 建物の ドアのまえに 立って **上向きで 話す** と 入れます（パチモンセンター / パチマート）
- NPCに 話しかけると クエストや ヒントが もらえます

## 目標

パチもん島で 御三家（フシギダメ / ヒトカゲン / ゼニガメラ）を 選び、
草むらで パチモンを 捕まえて 育て、島の 4人 の トレーナー（ムシトリスト・タンバリン・ウキビト）を 倒した あと、
東の 浜辺に いる ライバル **パチロー** を 倒せば エンディング です。

## システム

- **パチモン 21種**（御三家 + 進化系 を ふくむ。名前は すべて 本家から ほんの少し だけ 変えてある）／ **わざ 38種**（PP・優先度・まひ・やけど・ねむり・ランク変動）
- **10タイプ** の 相性（ばつぐん / いまひとつ / こうかなし）
- レベル到達で **進化**（一部 の み）
- **パーティ 6匹 + ボックス**、先頭交代は メニューの パーティ から
- **パチモンセンター**（無料 かいふく）と **パチマート**（パチコインで 買い物）
- **パチずかん**（未捕獲は シルエット表示）
- 戦闘不能で ひなん（センターへ 帰される）、マネーは 半分 こわれない（パクリ なので 優しい）
- **BGM 内蔵** — タイトル / ワールド / バトル / しょうりジングル / エンディング の チップチューン5曲（WebAudio で 生成、画像・音声ファイル なし）
- バトルの **ダメージポップ・きゅうしょフラッシュ・ログアニメ** つき
- **オートセーブ** — ブラウザの localStorage に 保存（キー `pachimon_save_v1`）
  - 消したい 場合: メニュー → レポート →「さいしょから やりなおす」
- 効果音・BGMとも メニュー → レポート →「サウンド」で ON/OFF

## ファイル構成

```
index.html      画面構成（タイトル/バトル/HUD/モーダル）
style.css       すべての スタイル
data.js         タイプ相性 / わざ / 種族 / エンカウント / トレーナー / アイテム
sprites.js      パチモン・人間 スプライト（Canvas 手描き、画像ファイル なし）
game.js         マップ / 入力 / ダイアログ / メニュー / セーブ
battle.js       バトル エンジン（ダメージ計算 / 捕獲 / 経験値 / 進化）
screenshots/    ビジュアル ギャラリー（ゲーム には 無関係）
```

## 技術メモ

- ビルド ツール 不要。HTML + CSS + classic JS のみ（module も bundler も 不使用）
- ワールド は 44×36 タイル（1タイル 36px）。草原 / 森 / 岩場 の 3ゾーン
- スプライトは `drawPachimon(ctx, id, x, y, scale, time, opts)` で 毎フレーム 描く 方式 の ため、
  拡大 しても ボケず、絵 の 追加 は `sprites.js` の `ART` 表に 1行 足す だけ
- BGMは `game.js` の `Music` オブジェクト（音符テーブル + 先読みスケジューラ）。曲 の 追加 は `Music.themes` に 1曲 分の データ を 足す だけ
- データ（種族値・わざ・エンカウント）は `data.js` に 集中。バランス調整 は そこ で
- キーボード そうさ は `game.js` の `moveFocus` / `focusables` / `trapFocus` で 実装。
  div 型 の クリック要素 は `tabindex="0" data-kbd` を つけると Enter / Space で はっか される
